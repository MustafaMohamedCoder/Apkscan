# ماسح الحسابات - Masah Hisabat

تطبيق أندرويد عربي (RTL) كامل لمسح أكواد QR والحسابات، يعمل محليًا بدون إنترنت.

## المميزات

- شاشة تسجيل دخول مع خيار "تذكرني"
- الواجهة الرئيسية مع بطاقة الترحيب وآخر العمليات
- السكنر (كاميرا + معرض الصور)
- المجموعات: فقاعات رسائل بأسلوب واتساب مع دعم النص والصور
- الفواتير مع عارض صور بالحجم الكامل والتكبير
- البحث الشامل
- المزامنة عبر الشبكة المحلية (UDP broadcast + TCP sync)
- إدارة الفريق (لحساب mustafa فقط)
- الوضع الليلي/النهاري
- حفظ البيانات في مجلد خارجي دائم (Documents/MasahHisabat)

## التقنية

- **اللغة:** Kotlin
- **minSdk:** 26 — **targetSdk:** 34
- **مكتبات:** Material Design 3، Gson، AndroidX (AppCompat، RecyclerView، ConstraintLayout، ViewPager2)
- **البناء:** Gradle 8.5 مع Kotlin DSL (JDK 21)

## البناء

```bash
export ANDROID_HOME=<مسار Android SDK>
./gradlew assembleDebug
```

## بيانات الدخول الافتراضية

- اسم المستخدم: `mustafa`
- كلمة المرور: `0`
