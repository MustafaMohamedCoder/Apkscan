# خريطة نقل واجهة Apkscan-by-gemini إلى تطبيق ماسح الحسابات

## المبدأ

سيبقى تطبيق أندرويد أصليًا وتبقى كل وظائفه الحالية، بما فيها التخزين الخارجي والمزامنة المحلية والماسح وسلة المحذوفات. يقتصر النقل على **الهوية المرئية وترتيب العناصر** المستلهمين من واجهة `Apkscan-by-gemini`، ولا يستبدل الشاشات الأصلية بصفحات ويب.

## خريطة المكونات

| واجهة المصدر | المقابل في أندرويد | التعديل المخطط |
|---|---|---|
| رأس العلامة والتحكم بالمظهر | `activity_main.xml` | شريط علوي مدمج في محتوى اللوحة مع أزرار إجراءات مستديرة، مع إبقاء زر الوضع ضمن التنقل الحالي لتجنب تغيير السلوك. |
| بطاقة الترحيب المتدرجة | `fragment_home.xml` | إضافة بطاقة علوية ذات تدرج Teal ونسخ بيضاء عالية التباين، مع زر التحليلات القائم. |
| بطاقات مؤشرات الأداء الثلاثة | `fragment_home.xml` | تحويل ملخص الفواتير والمجموعات وحالة البيانات إلى بطاقات KPI بحواف ناعمة وشارات حالة. |
| شبكة الإجراءات السريعة | `fragment_home.xml` | اعتماد بطاقات إجراءات متساوية بصريًا، مع ربطها بأزرار السكانر والمجموعات والبحث والإعدادات الموجودة. |
| قائمة المجموعات والفرز | `fragment_groups.xml` و`item_group.xml` | اعتماد رأس واضح، حقل بحث مدمج، بطاقات مجموعات ذات شريط إحصاءات وأزرار أقل ازدحامًا. |
| شريط التنقل السفلي | `activity_main.xml` | الحفاظ على الترتيب الوظيفي الحالي، مع إبراز زر الماسح كزر مركزي متدرج وتحسين حالات التحديد. |
| حقول البحث والإعدادات | `fragment_search.xml` و`fragment_settings.xml` | توحيد الحواف والألوان ومساحات البطاقات والحالات الفارغة لتطابق أسلوب المصدر. |

## قرارات التوافق

1. تعتمد الطباعة على **Tajawal** الموجودة أصلًا في التطبيق، مع أوزان أعلى للعناوين وشارات الحالة كما في المصدر.
2. تستخدم البطاقات نصف قطر بين `20dp` و`28dp`، وخلفيات سطحية واضحة في النهار و`#18202A` تقريبًا في الليل، مع تباين كافٍ للنصوص.
3. يبقى دعم RTL والمحتوى العربي والوظائف الحالية دون تغيير في معرّفات الواجهات المرتبطة بمنطق Kotlin.
4. يقتصر التعديل الأول على الصدفة العامة واللوحة الرئيسية والمجموعات، ثم تمتد اللغة البصرية إلى بقية التبويبات عبر الموارد المشتركة.
