# ماسح الحسابات

> **تطبيق أندرويد عربي يعمل محليًا لإدارة الحسابات والمجموعات والفواتير والرسائل والصور، دون الاعتماد على الإنترنت أو خدمات Google.**

يوفر التطبيق تجربة عربية كاملة من اليمين إلى اليسار، ويعمل على الهواتف والأجهزة اللوحية، بما فيها أجهزة هواوي وبيئات EMUI. يركز على تنظيم العمل والخصوصية؛ إذ يحفظ البيانات في مجلد خارجي دائم، ويتيح تبادل البيانات والتحديثات بين الأجهزة عبر شبكة Wi‑Fi المحلية.

يمكن قراءة التفاصيل الكاملة في [دليل ماسح الحسابات](دليل_ماسح_الحسابات.md).

## المميزات

| المجال | التنفيذ |
|---|---|
| **تسجيل الدخول** | شاشة دخول عربية بملء الشاشة، خيار «تذكرني»، وعبارة التطوير في أسفل شاشة الدخول فقط. |
| **الواجهة والمظهر** | هوية Teal وخط Tajawal وشريط تنقل سفلي مبسط، مع وضع نهاري وليلي وتلقائي يتبع إعداد الهاتف. |
| **المجموعات والفواتير** | مجموعات قابلة للتسمية والتثبيت والفرز، ورسائل نصية وصورية بأسلوب محادثة مع التعديل والمشاركة وحالة المشاهدة. |
| **الصور** | عرض بملء الشاشة، انتقال بالسحب بين الصور، وتكبير وتصغير بالإيماءات. |
| **إدارة الفريق** | إضافة وتعديل المستخدمين مع الحالة والصلاحيات، وإظهارها للمسؤول المصرح له فقط. |
| **البحث والتقارير** | بحث محلي محسّن، تقارير يومية، وإحصاءات قابلة للمراجعة والمشاركة محليًا. |
| **حفظ البيانات** | تخزين دائم في `Documents/MasahHisabat` للمجموعات والرسائل والمرفقات، حتى لا تضيع بعد إعادة تثبيت التطبيق ما لم يُحذف المجلد يدويًا. |
| **المزامنة المحلية** | مزامنة يدوية مع تقدم واضح، ومزامنة تلقائية ثنائية الاتجاه للمجموعات والفواتير والصور بعد تسجيل الدخول بين الأجهزة على الشبكة نفسها. |
| **حسابات المستخدمين** | مزامنة مستقلة تلقائية لحسابات جهاز الإدارة، مع توحيد أسماء المستخدمين لمنع أخطاء الدخول بين الأجهزة. |
| **التحديث المحلي** | اكتشاف الإصدار الأحدث ونقل APK على الشبكة المحلية مع التحقق من سلامة الملف وإشعار نجاح مرئي. |

## كيفية عمل المزامنة التلقائية بعد تسجيل الدخول

بعد تسجيل الدخول، يبدأ التطبيق اكتشاف الأجهزة التي تعمل على شبكة Wi‑Fi المحلية نفسها. عند العثور على جهاز متاح، يتبادل الطرفان المجموعات والفواتير والصور المرفقة ويُدمجان العناصر الجديدة في الاتجاهين. لا تحذف هذه العملية البيانات المحلية، وينشئ التطبيق نسخة احتياطية وقائية قبل تطبيق بيانات جديدة. توثق حالات النجاح أو فشل الاتصال في سجل المزامنة، وتبقى المزامنة اليدوية متاحة عند الحاجة إلى متابعة تقدّم النقل بصورة مباشرة.

> **طريقة الاختبار:** ثبّت النسخة نفسها على جهازين، وصلهما بالشبكة المحلية نفسها، وافتح التطبيق وسجّل الدخول على الجهازين. تبدأ مزامنة بيانات المجموعات والفواتير تلقائيًا بعد الدخول.

## التقنية

| العنصر | التفاصيل |
|---|---|
| اللغة | Kotlin |
| الحد الأدنى لأندرويد | Android 8.0 — API 26 |
| الهدف | API 34 |
| الواجهة | Material Design 3 وAndroidX وViewPager2 |
| البيانات | Gson وتخزين محلي خارجي دائم |
| الاتصال المحلي | اكتشاف UDP ونقل TCP |
| البناء | Gradle 8.5 مع Kotlin DSL وJDK 21 |
